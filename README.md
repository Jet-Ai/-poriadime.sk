# PORIADIME — website

Static, responsive Slovak landing page for the PORIADIME cleaning company.

## Before launch
1. Connect the domain `poriadime.sk`.
2. Replace the placeholder contact area with the real phone/e-mail.
3. Connect the contact form to an email/form backend.
4. Confirm the legal company name and trademark/domain availability before publishing the final brand.
5. Add real business photos and real reviews only after they exist.

The page is intentionally built without stock photos or fake reviews, so the first version can launch cleanly and honestly.
